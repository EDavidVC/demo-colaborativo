# Demo colaborativo

Repositorio de demostración para practicar colaboración en un proyecto **Node.js**.

## Requisitos

- [Node.js](https://nodejs.org/) 18 o superior
- npm (incluido con Node.js)

## Instalación

```bash
git clone <url-del-repositorio>
cd demo-colaborativo
npm install
```

## Uso

```bash
npm start
```

## Scripts

| Script        | Descripción                          |
| ------------- | ------------------------------------ |
| `npm start`   | Arranca la aplicación                |
| `npm test`    | Ejecuta las pruebas                  |
| `npm run dev` | Arranca en modo desarrollo (watch)   |

## Estructura del proyecto

```text
demo-colaborativo/
├── src/           # Código fuente
├── test/          # Pruebas
├── package.json   # Dependencias y scripts
└── README.md
```

## Contribuir

1. Crea una rama a partir de `main`.
2. Haz tus cambios y súbelos.
3. Abre un pull request describiendo qué cambió y por qué.

Este repositorio es un **demo**: úsalo para practicar commits, ramas y revisiones de código.
